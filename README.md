## Engineering thesis application
#### AGH University of Science and Technology, Faculty of Computer Science


### Title
An application for visualizing the flow of activations and gradients in artificial neural networks

### Description
The goal of the project is to create a modern application for visualizing processes in artificial neural networks. The application should present the architecture of a neural network implemented in the PyTorch framework in an engaging manner (in 2D or 3D, optionally with animations). Its functionality includes visualizing neuron activations during inference and gradients during training. Additionally, the application should allow for both the accumulation and analysis of data from individual batches or series of batches, as well as the presentation of single events in real time.
